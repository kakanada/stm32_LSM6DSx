# Настройка периферии в CubeMX для lsm6dsx

Библиотека сама не настраивает SPI/I2C — она только использует уже
инициализированный CubeMX-кодом хэндл. Ниже — что именно нужно выставить в
CubeMX, чтобы `LSM6DSX_Init` и операционные функции заработали корректно.
Используется ровно один из трёх интерфейсов на датчик (SPI 4-wire, SPI
3-wire или I2C) — настраивайте только нужный раздел.

## SPI 4-wire (`LSM6DSX_IF_SPI4`)

| Параметр CubeMX | Диапазон | Рекомендуемое значение | Пояснение |
|---|---|---|---|
| Mode | Full-Duplex Master / Half-Duplex Master / ... | **Full-Duplex Master** | Библиотека вызывает `HAL_SPI_Transmit` и `HAL_SPI_Receive` как отдельные полнодуплексные транзакции — Half-Duplex сюда не подходит (это режим SPI3). |
| Data Size | 4–16 бит | **8 бит** | Все регистры датчика и протокол чтения/записи — байтовые; библиотека шлёт/принимает `uint8_t`. |
| First Bit | MSB First / LSB First | **MSB First** | Формат команд LSM6DSx — MSB первым, это стандартное требование датчика, не настраивается программно в библиотеке. |
| CLK Polarity (CPOL) | Low / High | **High** (CPOL=1) | Вместе с CPHA=1 даёт Mode 3, которого требует LSM6DSx (датчик поддерживает Mode 0 и Mode 3 — библиотека ориентируется на Mode 3 как указанный в даташите по умолчанию). |
| CLK Phase (CPHA) | 1 Edge / 2 Edge | **2 Edge** (CPHA=1) | См. выше — вместе с CPOL=High это Mode 3. |
| Prescaler (Baud Rate) | по шкале делителей шины | значение, дающее **≤ 10 МГц** на выходе SPI | Максимальная частота SPI по даташиту LSM6DSx — 10 МГц; берите ближайший делитель снизу от частоты шины APB, на которой висит SPI. |
| CS (NSS) | Hardware NSS / Software (GPIO) | **Software — отдельный GPIO Output** | Библиотека сама дёргает CS через `HAL_GPIO_WritePin` (поля `cs_port`/`cs_pin` в конфиге) — аппаратный NSS не используется и должен быть отключён (`NSS = Software` в настройках SPI). GPIO — Output Push-Pull, начальное состояние **High** (CS неактивен). |

## SPI 3-wire (`LSM6DSX_IF_SPI3`)

Всё как для SPI 4-wire (Data Size, First Bit, CPOL/CPHA, Prescaler, CS),
кроме:

| Параметр CubeMX | Диапазон | Рекомендуемое значение | Пояснение |
|---|---|---|---|
| Direction | 2 Lines / 2 Lines RXONLY / **1 Line** | **1 Line** (`SPI_DIRECTION_1LINE`, half-duplex) | Физически одна линия данных (MOSI/MISO объединены на уровне датчика). Библиотека сама переключает направление передачи битом `BIDIOE` регистра `CR1` (`lsm6dsx_spi3_set_tx/rx`) перед каждой фазой транзакции — в CubeMX достаточно выбрать режим "1 Line", направлением в рантайме управляет библиотека. |

## I2C (`LSM6DSX_IF_I2C`)

| Параметр CubeMX | Диапазон | Рекомендуемое значение | Пояснение |
|---|---|---|---|
| Mode | I2C / SMBUS | **I2C** | Датчик — обычное I2C-устройство, SMBus-расширения (PEC, alert) не используются. |
| I2C Speed Mode | Standard (100 кГц) / Fast (400 кГц) / Fast+ (1 МГц) | **Standard или Fast** | LSM6DSx поддерживает Standard (100 кГц) и Fast (400 кГц) режимы I2C по даташиту; Fast+ датчиком не поддерживается — не выбирайте его. |
| Own Address | 7-бит/10-бит адрес | не используется (режим Master) | Библиотека работает только как I2C-master, опрашивающий датчик — собственный адрес MCU на этой шине роли не играет. |
| 7-битный адрес датчика (`i2c_address` в конфиге, не поле CubeMX-периферии) | `0x6A` или `0x6B` | **`0x6A`**, если вывод SDO/SA0 подтянут к **GND**; **`0x6B`**, если подтянут к **VDD** | Это не настройка самой периферии I2C, а адрес конкретного устройства на шине — библиотека использует его как есть в `HAL_I2C_Mem_Read/Write`, значение задаётся в `LSM6DSX_Config_t.i2c_address` при вызове `LSM6DSX_Init`, а не в CubeMX. |

## Условная компиляция SPI/I2C

Код каждой шины в `lsm6dsx.c` компилируется только при наличии
соответствующего define'а из `stm32*xx_hal_conf.h` — `HAL_SPI_MODULE_ENABLED`
и `HAL_I2C_MODULE_ENABLED` (CubeMX выставляет их сам в зависимости от того,
какие периферийные модули включены в проекте вкладкой Project Manager →
Advanced Settings / Pinout). Если в проекте задействован только один
интерфейс — второй define отсутствует, и код для него просто не попадает в
сборку; добавлять что-либо вручную для этого не нужно.

## Общее требование

Указанные выше периферийные модули (SPI или I2C) должны быть
инициализированы штатным CubeMX-кодом (`MX_SPIx_Init()` / `MX_I2Cx_Init()`)
**до** вызова `LSM6DSX_Init()` — библиотека ожидает уже рабочий хэндл.
